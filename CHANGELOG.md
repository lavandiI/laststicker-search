# LastSticker Search - Changelog

## Правила ведения CHANGELOG

### Структура записей
```
### [Версия] - Дата
#### Добавлено
- Новая функциональность

#### Исправлено
- Исправленные баги

#### Изменено
- Изменения в существующем функционале

#### Удалено
- Удаленный функционал
```

### SemVer (Semantic Versioning)
- **MAJOR** (1.0.0 → 2.0.0) - несовместимые изменения API
- **MINOR** (1.0.0 → 1.1.0) - новый функционал с обратной совместимостью  
- **PATCH** (1.0.0 → 1.0.1) - исправления багов

### Процесс
1. Все изменения добавлять в раздел `[Unreleased]`
2. При релизе переименовать в `[Версия] - Дата` и обновить версию в `manifest.json`

## Краткий справочник проекта

> Chrome Extension для индексации и поиска сообщений на laststicker.ru

### Технологии
- **Тип**: Chrome Extension (Manifest V3)
- **Язык**: JavaScript (ES6+)
- **Лinting**: ESLint
- **Форматирование**: Prettier
- **Хранение**: chrome.storage.local
- **Тестирование**: Jest

### Основные файлы

| Файл | Назначение |
|------|------------|
| [`manifest.json`](manifest.json:1) | Конфигурация расширения |
| [`background.js`](background.js:1) | Service Worker (фоновый скрипт) |
| [`content.js`](content.js:1) | Content script (извлечение сообщений со страницы) |
| [`inline-panel.js`](inline-panel.js:1) | Встроенная панель на странице |
| [`inline-ui.js`](inline-ui.js:1) | UI-компоненты встроенной панели |
| [`inline-storage.js`](inline-storage.js:1) | Работа с хранилищем для inline-панели |
| [`inline-styles.css`](inline-styles.css:1) | Стили встроенной панели |
| [`tests/`](tests/) | Unit-тесты |

### Команды
```bash
npm install      # Установка зависимостей
npm run lint     # Запуск ESLint
npm run format   # Запуск Prettier
npm test         # Запуск Jest
```

## История версий

### [1.1.0] - 2026-03-07
#### Добавлено
- Поиск внутри отдельного диалога/разговора (страница /users/my_talks/{id})
- Панель поиска на странице диалога с отображением количества сообщений
- Автоматическая загрузка всех страниц разговора для полной индексации
- Парсинг изображений в сообщениях (функция parseImagesFromHtml)
- Unit-тесты для функции парсинга изображений
- Добавлены иконки расширения всех размеров (16, 32, 48, 128px)

#### Исправлено
- Исправлены синтаксические ошибки в inline-panel.js и inline-ui.js (сломанные вызовы функций)
- Добавлен флаг InlinePanelReady для корректной инициализации панели
- Исправлена ошибка "InlinePanel still not ready after injection"
- Добавлена логика повторных попыток (retry) при загрузке зависимостей и inline-panel (до 10 попыток с интервалом 200ms)

#### Изменено
- Парсинг сообщений: изображения извлекаются и индексируются всегда (даже при наличии текста)
- Изображение добавляется к тексту сообщения в формате `[Image: src1, src2, ...]`
- Улучшен парсинг сообщений (извлечение ID, timestamp, партнёра)
- Заменена навигация через chrome.tabs.update на прямые fetch() вызовы при индексации
- Улучшена скорость и надежность процесса индексации
- Оптимизирована локальная индексация при входе в диалог: используются закэшированные сообщения из глобальной индексации вместо повторного сетевого запроса

### [1.0.1] - 2026-03-07
#### Исправлено
- Статистика (кол-во диалогов/сообщений) теперь обновляется без перезагрузки страницы после индексации
- Панель теперь отображается только на странице /users/my_talks/, а не на /users/my_talks/hide/
- Исправлено overflow для поля поиска

#### Изменено
- Обновлены стили панели под дизайн сайта (шрифты, цвета, размеры)
- Кнопка "Индексировать" теперь более тёмного синего цвета
- Кнопка "Очистить" теперь менее яркого красного цвета
- Цифры диалогов и сообщений теперь того же цвета, что и кнопка "Индексировать"
- Поисковый ввод теперь с обычным (не жирным) шрифтом

#### Удалено
- Убрана функция перехода в диалог при клике или Enter на результате поиска

### [1.0.0] - 2026-03-06
#### Добавлено
- Базовая индексация диалогов с laststicker.ru
- Поиск по сообщениям и собеседникам
- Подсветка совпадений в результатах
- Статистика (кол-во диалогов/сообщений)
- Быстрый переход к диалогу из результатов
- Встроенная панель (inline-panel) для отображения на странице

#### Компоненты
- Popup-интерфейс с кнопками "Индексировать" и "Очистить"
- Content script для парсинга страниц
- Background service worker для коммуникации
- Локальное хранилище данных
