# LastSticker Search - Changelog

## Правила ведения CHANGELOG

### Структура записей

```
### [Версия] - Дата
#### Добавлено
- Новая функциональность

#### Исправлено
- Исправленные баги

#### Изменено
- Изменения в существующем функционале

#### Удалено
- Удаленный функционал
```

### SemVer (Semantic Versioning)

- **MAJOR** (1.0.0 → 2.0.0) - несовместимые изменения API
- **MINOR** (1.0.0 → 1.1.0) - новый функционал с обратной совместимостью
- **PATCH** (1.0.0 → 1.0.1) - исправления багов

### Процесс

1. Все изменения добавлять в раздел `[Unreleased]`
2. При релизе переименовать в `[Версия] - Дата` и обновить версию в `manifest.json`

## История версий

### [1.5.0] - 2026-11-01

#### Добавлено

- Отдельная панель поиска по сообщениям форума
- Индексация выбранной темы форума в IndexedDB с прогрессом и отменой
- Глобальный поиск по уже проиндексированным темам
- Переход к точному комментарию `#c{id}` и подсветка целевого сообщения
- Обновление темы с последней проиндексированной страницы
- Очистка на странице темы удаляет только эту тему; на главной форума — весь форумный индекс
- Полная переиндексация выполняется через очистку темы и повторную индексацию

#### Изменено

- Версия Manifest и пакета — 1.5.0
- Диалоги продолжают храниться в `chrome.storage.local`; форум использует IndexedDB
- На странице темы поиск всегда ограничен этой темой; на главной форума — по всем проиндексированным темам
- Кнопка «Переиндексировать» убрана
- Повторное обновление темы без новых сообщений больше не перезаписывает индекс
- В README, CHANGELOG и политике конфиденциальности описаны форумный индекс и его хранение

#### Техническое

- `forum-parser.js`, `forum-storage.js`, `forum-indexer.js`
- Storage-RPC `forumStats`, `forumSearch`, `forumClear`, `forumDeleteTopic`
- Generation-защита от записи после очистки форума
- 93 теста Jest, включая парсер, IndexedDB и панель форума

### [1.4.0] - 2026-11-01

#### Добавлено

- Offscreen-индексатор: индексация не зависит от активной вкладки laststicker
- Автообновление индекса каждые 6 часов, включено по умолчанию
- Проверка непрочитанных сообщений через AJAX-эндпоинт сайта
- Автообновление пропускается, если есть непрочитанные или нет полного индекса
- Настройка автообновления в панели, прогресс в бейдже иконки
- Общий `parser.js` для парсинга страниц
- Разрешения `offscreen` и `alarms`
- Storage-RPC для offscreen и миграция старого offscreen-localStorage в `chrome.storage.local`

#### Изменено

- Ручная индексация сохраняет результат через offscreen-индексатор
- Существующий непустой индекс считается полным
- Прогресс и ошибки индексации обновляются без перезагрузки страницы
- Очистка отменяет активную индексацию; индексатор не сохраняет результат после очистки
- HTML очищается от inline-обработчиков перед `DOMParser`

### [1.3.1] - 2026-11-01

#### Добавлено

- Тесты парсеров на обезличенных HTML-фикстурах: messageId, даты, изображения, дедупликация
- Тесты на XSS-подобный текст и защиту от исполнения HTML
- Тест на повторные запросы и разбор `Retry-After`
- GitHub Actions workflow для сборки ZIP и публикации Release по тегу

#### Изменено

- Сетевые запросы повторяются на `429`/`503` и сетевых ошибках с экспоненциальной задержкой
- Повторы учитывают отмену индексации
- Свой ID определяется по странице, а не по захардкоженному `83061`
- Удалены отладочные сообщения с именами собеседников

### [1.3.0] - 2026-11-01

#### Добавлено

- Клавиатурная навигация по результатам: стрелки, Enter, Escape
- Горячая клавиша `/` для фокуса на поиске
- Баннер устаревшего индекса с кнопкой обновления
- Раскрываемые подробности ошибок индексации и кнопка «Повторить»
- Одноразовое предупреждение о том, что сайт может отметить диалоги прочитанными
- Размер локального индекса в статистике и предупреждение о приближении к лимиту
- ARIA-атрибуты и видимый focus ring для панели и результатов

#### Изменено

- Убрано разрешение `tabs`: URL активной вкладки laststicker.ru доступен через host permissions
- Политика конфиденциальности и обоснования разрешений обновлены

### [1.2.0] - 2026-10-31

#### Добавлено

- Исправлено извлечение `messageId` и дедупликация: два разных сообщения с одинаковым текстом и временем больше не склеиваются
- Исправлен CORS при загрузке страниц диалогов (`www.laststicker.ru` вместо `laststicker.ru`)

## Краткий справочник проекта

> Chrome Extension для индексации и поиска сообщений на laststicker.ru

### Технологии

- **Тип**: Chrome Extension (Manifest V3)
- **Язык**: JavaScript (ES6+)
- **Линтинг**: ESLint
- **Форматирование**: Prettier
- **Хранение**: localStorage (сообщения) и chrome.storage.local (настройки)
- **Тестирование**: Jest

### Основные файлы

| Файл                                       | Назначение                                        |
| ------------------------------------------ | ------------------------------------------------- |
| [`manifest.json`](manifest.json:1)         | Конфигурация расширения                           |
| [`background.js`](background.js:1)         | Service Worker (фоновый скрипт)                   |
| [`content.js`](content.js:1)               | Content script (извлечение сообщений со страницы) |
| [`inline-panel.js`](inline-panel.js:1)     | Встроенная панель на странице                     |
| [`inline-ui.js`](inline-ui.js:1)           | UI-компоненты встроенной панели                   |
| [`inline-storage.js`](inline-storage.js:1) | Работа с хранилищем для inline-панели             |
| [`inline-styles.css`](inline-styles.css:1) | Стили встроенной панели                           |
| [`tests/`](tests/)                         | Unit-тесты                                        |

### Команды

```bash
npm install      # Установка зависимостей
npm run lint     # Запуск ESLint
npm run format   # Запуск Prettier
npm test         # Запуск Jest
```
