## LastSticker Search

**LastSticker Search** — это расширение Chrome (Manifest V3), которое индексирует ваши диалоги на `laststicker.ru` и позволяет быстро по ним искать.

Репозиторий: https://github.com/lavandiI/laststicker-search

### Возможности

- **Индексация диалогов** с `laststicker.ru` через кнопку «Индексировать» на странице.
- **Индексация скрытых диалогов** (`/users/my_talks/hide/`).
- **Поиск по сообщениям и собеседникам** (строка поиска во встроенной панели).
- **Поиск внутри отдельного диалога** (страница `/users/my_talks/{id}/`).
- **Подсветка совпадений** в найденных сообщениях.
- **Статистика**: количество диалогов и сообщений.
- **Встроенная панель** — поиск прямо на странице сайта.
- **Включение и отключение** кликом по иконке расширения.

### Установка в Chrome (режим разработчика)

1. Скачайте или клонируйте репозиторий с расширением в отдельную папку.
2. Откройте `chrome://extensions/` в браузере Chrome.
3. Включите режим разработчика (Developer mode) в правом верхнем углу.
4. Нажмите «Load unpacked» / «Загрузить распакованное расширение».
5. Укажите папку с файлами расширения (где лежит `manifest.json`).

После этого расширение активируется на страницах `laststicker.ru`.

### Как пользоваться

1. Откройте страницу `/users/my_talks/` на `laststicker.ru`.
2. Нажмите кнопку **«Индексировать»** — начнётся сбор и сохранение сообщений.
3. В строке поиска введите текст или имя собеседника — результаты обновятся автоматически.
4. Для поиска внутри одного диалога откройте его страницу — панель будет искать только по этому диалогу.
5. Кнопка **«Очистить»** полностью удаляет индексированные сообщения из локального хранилища.

Клик по иконке расширения включает и отключает его. Во включённом состоянии иконка цветная, в выключенном — чёрная.

### Разработка

Требуется Node.js 20.19 или новее.

В проекте настроены базовые инструменты:

- **ESLint** — статический анализ JavaScript.
- **Prettier** — автоформатирование кода.
- **Jest** — unit-тесты.

Команды:

- `npm install` — установка зависимостей для разработки.
- `npm run lint` — запуск ESLint.
- `npm run lint:fix` — автоматическое исправление некоторых проблем.
- `npm run format` — автоформатирование кодовой базы Prettier.
- `npm test` — запуск unit-тестов.

### Ограничения и заметки

- Расширение работает только с сайтом `laststicker.ru`.
- Сообщения сохраняются локально в `localStorage`, настройка включения — в `chrome.storage.local`. Данные не отправляются на внешние серверы.
- Объём `localStorage` ограничен квотой браузера (обычно 5–10 МБ).
- При большом количестве сообщений первая индексация может занять немного времени.
