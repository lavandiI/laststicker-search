# Chrome Web Store — карточка LastSticker Search

## Основное

**Название:** LastSticker Search

**Краткое описание (до 132 символов):**

Поиск по вашим диалогам и форуму laststicker.ru. Индексы хранятся локально.

**Категория:** Tools (группа Productivity)

**Язык:** Русский

**Видимость:** Public — опубликовано для всех

**Одно предложение о назначении (single purpose):**

Локальная индексация и поиск сообщений в собственных диалогах и на форуме laststicker.ru.

## Подробное описание

LastSticker Search — расширение для Chrome, которое помогает быстро находить сообщения в ваших собственных диалогах и на форуме laststicker.ru.

Возможности:

- индексация основных и архивных диалогов;
- поиск по тексту сообщений и именам собеседников;
- поиск внутри отдельного диалога;
- отдельная панель поиска по сообщениям форума;
- индексация выбранной темы форума;
- глобальный поиск по уже проиндексированным темам;
- переход к найденному сообщению или комментарию на нужной странице;
- подсветка найденного сообщения;
- статистика по диалогам, темам и сообщениям;
- инкрементальная индексация: неизменившиеся диалоги пропускаются, а тема обновляется только при появлении новых сообщений;
- прогресс индексации и кнопка отмены;
- клавиатурная навигация: стрелки, Enter, Escape, `/` для фокуса на поиске;
- автообновление индекса диалогов каждые 6 часов, если нет непрочитанных сообщений;
- напоминание об устаревшем индексе и подробности ошибок загрузки;
- хранение индексов только локально в браузере.

Как это работает:

1. Диалоги: откройте свою страницу диалогов на laststicker.ru.
2. Нажмите «Индексировать» во встроенной панели.
3. Дождитесь окончания индексации.
4. Введите запрос в строку поиска.

Форум:

1. Откройте тему на laststicker.ru.
2. Нажмите «Индексировать тему».
3. Ищите по тексту или автору: на странице темы поиск идёт только по ней, на главной форума — по всем проиндексированным темам.
4. Клик по результату открывает нужную страницу и подсвечивает комментарий.

Важно:

- расширение не связано с администрацией laststicker.ru;
- для работы нужен вход в ваш аккаунт на сайте;
- при индексации диалогов расширение открывает их страницы, поэтому сайт может отметить диалоги прочитанными;
- автообновление диалогов включено по умолчанию, работает раз в 6 часов и пропускается при наличии непрочитанных;
- автообновление начинает работать после первого полного индекса диалогов;
- автообновление не работает, когда браузер закрыт;
- форум индексируется только вручную; автоматического обхода всего форума нет;
- индекс диалогов хранится в `chrome.storage.local`, индекс форума — в IndexedDB;
- данные не отправляются разработчику и не продаются третьим лицам.

## Разрешения и обоснование

**storage**

Нужно для локального хранения индекса диалогов в `chrome.storage.local` и индекса форума в IndexedDB, а также последнего поискового запроса и времени индексации.

**scripting**

Нужно для внедрения встроенной панели поиска и парсеров сообщений на страницы диалогов и форума laststicker.ru.

**offscreen**

Нужно для локального парсинга HTML в offscreen-документе без открытой вкладки laststicker.ru — как для диалогов, так и для форума.

**alarms**

Нужно для периодической проверки автообновления индекса диалогов раз в 6 часов, если пользователь не отключил его.

**Host permissions — laststicker.ru и www.laststicker.ru**

Нужны для чтения страниц собственных диалогов и форума пользователя на laststicker.ru. Доступа к другим сайтам нет.

## Privacy practices

**Single purpose:** локальная индексация и поиск сообщений в собственных диалогах и на форуме laststicker.ru.

**Remote code:** No.

**Data usage:**

- Personal communications — да, текст сообщений в диалогах и комментариев на форуме; хранятся локально, не передаются.
- Website content — да, страницы диалогов и форума; хранятся локально в виде проиндексированных сообщений.
- Personally identifiable information — да, имена собеседников и авторов комментариев; хранятся локально.
- Web history — нет.
- Location — нет.
- Financial information — нет.
- Health information — нет.
- Authentication information — нет; расширение использует существующую сессию браузера, но не читает и не сохраняет пароли.

**Data sale/transfer:** данные не продаются, не передаются третьим лицам и не используются для рекламы или оценки кредитоспособности.
