# План: Автоматическая индексация всех разделов

## Проблема
Текущая реализация требует от пользователя:
1. Зайти в "Мои разговоры" → нажать "Индексировать"
2. Зайти в "Скрытые" → нажать "Индексировать"

## Цель
По кнопке "Индексировать" автоматически собирать сообщения из обоих разделов.

## Реализация

### Вариант выбран: Автоматическое переключение страниц в popup.js

#### Изменения в `popup.js`:

1. **Добавить функцию `indexAllSections()`** - основная функция для индексации всех разделов
   - Последовательно открывает страницы:
     - `/users/my_talks/` (Мои разговоры)
     - `/users/my_talks/hide/` (Скрытые)
   - Для каждой страницы вызывает `extractMessages`
   - Объединяет результаты

2. **Изменить `onIndexClick()`** - вызывает `indexAllSections()` вместо одиночной индексации

3. **Обновить UI** - показывать прогресс (какой раздел обрабатывается)

#### Flow работы:
```
Пользователь нажимает "Индексировать"
         ↓
Показать: "Индексация Мои разговоры..."
         ↓
Открыть /users/my_talks/ → extractMessages
         ↓
Показать: "Индексация Скрытые..."
         ↓
Открыть /users/my_talks/hide/ → extractMessages
         ↓
Объединить результаты
         ↓
Сохранить в storage
         ↓
Показать результат
```

#### Технические детали:
- Использовать `chrome.tabs.update()` для переключения между страницами
- Ждать загрузки каждой страницы перед извлечением сообщений
- Объединять сообщения (удалять дубликаты по messageId)
- Показывать прогресс в UI

## Файлы для изменения:
- `popup.js` - основная логика автоматизации

## Результат:
Одна кнопка "Индексировать" собирает все сообщения из обоих разделов автоматически.
