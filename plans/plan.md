# Chrome Extension: LastSticker Message Search

## Описание
Расширение для Chrome, которое индексирует сообщения с сайта laststicker.ru и позволяет осуществлять поиск по ним в попапе.

## Архитектура

### Файлы расширения
```
laststicker-search/
├── manifest.json      # Конфигурация расширения
├── popup.html         # HTML popup
├── popup.js           # Логика popup
├── content.js         # Content script для извлечения сообщений
├── styles.css         # Стили для popup
└── icons/             # Иконки расширения
```

### Компоненты

1. **manifest.json**
   - Разрешения: activeTab, storage
   - Permissions для сайта laststicker.ru
   - Content scripts для извлечения данных

2. **popup.html**
   - Кнопка "Индексировать" - запускает сбор сообщений
   - Кнопка "Очистить" - удаляет все indexed данные
   - Поле поиска
   - Статистика: кол-во диалогов, кол-во сообщений
   - Результаты поиска с сортировкой (новые сверху)

3. **popup.js**
   - Обработчики кнопок
   - Логика поиска
   - Сортировка по дате (новые сверху)
   - Отображение статистики

4. **content.js**
   - Извлечение сообщений со страниц laststicker.ru
   - Парсинг HTML для получения данных сообщений
   - Отправка данных в popup/storage

## UI/UX

### Popup Layout
```
+---------------------------+
|  [Индексировать] [Очистить]|
+---------------------------+
|  Статистика:              |
|  Диалогов: XX             |
|  Сообщений: XXX           |
+---------------------------+
|  [Поиск...]               |
+---------------------------+
|  Результаты:              |
|  ------------------------|
|  @nick1                   |
|  > текст сообщения...     |
|  дата: XX.XX.XXXX         |
|  ------------------------|
|  @nick2                   |
|  > текст сообщения...     |
|  ...                      |
```

## Поток данных

1. Пользователь открывает popup
2. Нажимает "Индексировать"
3. Content script собирает все сообщения со страниц
4. Данные сохраняются в chrome.storage.local
5. При поиске - фильтрация и сортировка по дате (новые сверху)
6. Вывод результатов с ником собеседника сверху каждой группы

## Требования
- Chrome 88+
- manifest V3
- Политика конфиденциальности: все данные хранятся локально
