Chrome extension · Manifest V3

Все ваши диалоги и форум — в одном поиске

LastSticker Search индексирует ваши собственные диалоги и темы форума на laststicker.ru и помогает находить нужные сообщения за секунды. Индексы хранятся локально в браузере и никуда не отправляются.

Как установить Скачать ZIP

Возможности

Поиск по всем диалогам

Ищите по тексту сообщений и именам собеседников в основной и архивной переписке.

Переход к сообщению

Результат открывает нужную страницу диалога и подсвечивает найденное сообщение.

Инкрементальная индексация

Неизменившиеся диалоги пропускаются, поэтому повторная индексация проходит быстрее.

Прогресс и отмена

Видно, сколько диалогов обработано; длинную индексацию можно остановить.

Локальное хранение

Диалоги хранятся в chrome.storage.local, форум — в IndexedDB. Без аналитики, рекламы и внешних серверов.

Поиск внутри диалога

На странице отдельного разговора панель ищет только по нему и показывает количество сообщений.

Поиск по форуму

Отдельная панель на страницах форума: индексация темы, поиск по комментариям и переход к точному сообщению.

Глобальный поиск по темам

Ищет по всем уже проиндексированным темам и группирует результаты по темам.

Клавиатура

Стрелки выбирают результат, Enter открывает его, а / фокусирует поиск.

Контроль индекса

Видно размер индекса и дату обновления; панель предупредит об устаревании и ошибках загрузки.

Автообновление

Включено по умолчанию: раз в 6 часов обновляет полный индекс. Пропускается, если есть непрочитанные сообщения или браузер закрыт.

Тёмная тема

Оформление всего сайта и панелей поиска: переключатель, палитры «Графит» и «Чёрная», приглушение изображений. Настройки открываются по клику на иконку.

Как это выглядит

Встроенная панель появляется прямо на странице диалогов. Никаких отдельных окон и переключений между вкладками.

  • Индексация своих диалогов
  • Поиск по тексту и собеседнику
  • Переход к точному сообщению
  • Отдельный поиск по сообщениям форума
  • Статистика и дата последней индексации
  • Тёмная тема сайта и панелей

Установка

Chrome Web Store

Установите расширение из магазина — Chrome будет обновлять его автоматически.

Установить из Chrome Web Store

Вручную из ZIP

Скачайте архив, распакуйте его и загрузите папку через chrome://extensions → «Загрузить распакованное расширение».

Скачать последний релиз

Для работы нужен вход в ваш аккаунт на laststicker.ru. Расширение не связано с администрацией сайта. При индексации сайт может отметить открытые диалоги прочитанными.

Приватность по умолчанию

Текст сообщений, имена собеседников и служебные идентификаторы диалогов и форума хранятся только в вашем браузере. Расширение не отправляет их разработчику или третьим лицам.
