# Тёмная тема — ручная проверка

Проверять на распакованном расширении 1.6.0 в Chrome 109+ под своим аккаунтом.

## Матрица страниц

Для каждой страницы проверить выключенную и включённую тему, палитры «Графит» и «Чёрная».

- [ ] Главная `laststicker.ru`
- [ ] Каталог коллекций `/cards/`
- [ ] Коллекция и чек-лист `/cards/{collection}/`
- [ ] Карточка коллекции/лот в магазине
- [ ] Список аукциона `/auction/`
- [ ] Лот аукциона `/auction/post{id}/`
- [ ] Форум, главная `/blog/forum/`
- [ ] Тема форума `/blog/post{id}/`
- [ ] Список диалогов `/users/my_talks/`
- [ ] Отдельный диалог `/users/my_talks/{id}/`
- [ ] Архив диалогов `/users/my_talks/hide/`
- [ ] Профиль пользователя `/users/{id}/`
- [ ] Поиск по сайту `/search/?q=...`
- [ ] Формы: вход, регистрация, профиль, создание лота
- [ ] Пагинация, tooltip, autocomplete, select2, календарь, cookie consent

## Что проверить

- [ ] Нет светлых прямоугольников на тёмном фоне, кроме сторонних iframe.
- [ ] Текст читается: контраст не ниже 4.5:1 для обычного текста.
- [ ] Ссылки, hover и focus видимы.
- [ ] Таблицы, заголовки, границы и строки не сливаются.
- [ ] Поля ввода, select, textarea, checkbox и radio читаемы.
- [ ] Кнопки «Индексировать» (`#d7e0ff` / `#2444bc`) и «Очистить» (`#993333` / белый) не изменились.
- [ ] Жёлтая подсветка результата и целевого сообщения читаема.
- [ ] Логотип, обложки, сканы и аватарки не инвертированы.
- [ ] Приглушение изображений не затрагивает иконки и аватарки.
- [ ] Переключение темы применяется без перезагрузки на всех открытых вкладках.
- [ ] После перезапуска браузера настройки сохраняются.
- [ ] Переключатель явно показывает «Включена»/«Выключена».
- [ ] Тема всегда применяется ко всему сайту и панелям поиска.
- [ ] При загрузке нет заметной белой вспышки (после первого включения).
- [ ] Нет горизонтальной прокрутки и сдвигов вёрстки.
- [ ] Popup открывается по клику на иконку, все настройки доступны с клавиатуры.
- [ ] Сброс выключает тему, выбирает графит и отключает приглушение.

## Известные ограничения

- Реклама внутри сторонних iframe не перекрашивается.
- Некоторые очень старые страницы с нестандартными инлайновыми стилями могут требовать точечных правил; если тема ломает страницу, выключите её и пришлите URL.
- Тема не скрывает рекламу и не меняет структуру сайта.
- Физический размер IndexedDB и `chrome.storage.local` не связан с темой.
